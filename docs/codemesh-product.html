Map first. Read less.

Codemesh is a code knowledge graph for AI coding agents. It runs as an MCP server or a CLI, and it remembers what agents learn.

Average across 6 real repos with Claude Sonnet 4.6, Codemesh MCP vs. Grep + Read baseline. Earlier answer-first workflow.

The problem

Agents spend most tokens finding code

Before Agent→ Grep→ 50 matches→ Read 10 files→ Understand→ Work
After Agent→ codemesh_map→ expand branch→ read one symbol→ Work
Indexing

One command builds the graph

codemesh index parses the repo and writes a single SQLite file. No embeddings, no vector DB.

Example: 656 files → 16,733 symbols, 33,266 edges in ~10 s. Re-index is incremental.

The graph

Two layers: code facts and agent knowledge

The agent loop

Each session leaves the graph smarter

Toolbox

Ten tools, four jobs

Navigate

mapBrowse one level, follow links
sourceExact code for a symbol ID
inspectSymbol + its direct calls
hydrateReopen saved refs after handoff

Search

exploreSearch, context, impact
traceFollow call chains
answerRanked context in one call

Remember

enrichSave a summary for next time
workflowRecord a multi-file path
recallGet notes with freshness

Health

statusGraph stats and staleness

MCP names are prefixed codemesh_. CLI: codemesh explore <tool>.

Quick start

Three steps

1
npm install -g @pyalwin/codemesh
2
cd /your/project && codemesh index
3
{ "mcpServers": { "codemesh": {
    "command": "npx", "args": ["-y", "@pyalwin/codemesh"],
    "env": { "CODEMESH_PROJECT_ROOT": "/your/project" } } } }

Step 3 goes in .mcp.json (Claude Code) or .cursor/mcp.json. Or skip it and use the CLI.

Supports TypeScript, JavaScript, Python, Go, Rust, Java, C#, Ruby, PHP, C, C++, Swift, Kotlin, Dart. Source: github.com/pyalwin/codemesh
